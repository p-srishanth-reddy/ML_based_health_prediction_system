About This Project

This project, “AI-Based Early Prediction of Health Diseases Using Clinical Data Analytics,” is designed as an academic demonstration of how machine learning can be applied to public health datasets for risk screening.

Our Approach

We utilize clinical datasets from Kaggle and implement two distinct classification algorithms: Decision Trees and Random Forests. By preprocessing the data and tuning hyperparameters, we compare which model provides better accuracy and reliability for each condition.

Technical Stack
  • Backend: Python, Flask
  • ML: Scikit-Learn, Pandas, NumPy
  • Frontend: HTML5, CSS3, Bootstrap 5, JavaScript
Important: This is NOT a clinical tool. The results provided are based on statistical patterns in data and are intended for educational purposes only.
