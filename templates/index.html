Comparative Machine Learning Methodology

To evaluate model suitability across different clinical tasks, every module trains, cross-validates, and compares three distinct classifiers:

1
Logistic Regression

A calibrated parametric baseline. Models log-odds with balanced class weighting, offering straightforward clinical coefficient interpretation and stable probabilities.

2
Decision Tree

A non-parametric recursive partitioning classifier with tuned depth to prevent overfitting, offering transparent threshold rules for clinical indicators.

3
Random Forest Ensemble

An ensemble of 100 decorrelated decision trees using bootstrap aggregation, mitigating variance and producing robust ranking discrimination (ROC-AUC).
