AI-Based Early Prediction of Health Diseases

A clinical data analytics prototype using Machine Learning to identify early risks of common health conditions. This is an academic demonstration for educational purposes.

Project Methodology

Decision Tree

A non-parametric supervised learning method used for classification. It splits the data into branches based on feature values, creating a tree-like model of decisions.

Random Forest

An ensemble learning method that constructs a multitude of decision trees at training time and outputs the class that is the mode of the classes of the individual trees.
