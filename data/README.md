# Dataset Acquisition Instructions

To run this project, you need to download the following datasets from Kaggle and place them in the corresponding directories:

1. Blood Pressure:
   - Source: https://www.kaggle.com/datasets/pavanbodanki/blood-press
   - Path: data/blood_pressure/blood_press.csv

2. Diabetes:
   - Source: https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database
   - Path: data/diabetes/diabetes.csv

3. Anemia:
   - Source: https://www.kaggle.com/datasets/biswaranjanrao/anemia-dataset/data
   - Path: data/anemia/anemia.csv

4. Obesity:
   - Source: https://www.kaggle.com/datasets/fatemehmehrparvar/obesity-levels
   - Path: data/obesity/obesity.csv

Note: Ensure the filenames match the expected paths or update the data_loader.py configurations.
